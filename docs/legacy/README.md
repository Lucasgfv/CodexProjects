# Referências legadas

Os HTMLs desta pasta são as fontes originais usadas na migração das rotas:

- `indexx/Contrato de servico index.html`
- `indexx/MSG pronta index.html`

Eles não são servidos pela aplicação e devem permanecer preservados até que as
rotas Next.js tenham sido validadas funcionalmente.

O arquivo `public/autcontabil-logo.jpg` é extraído do HTML do contrato por:

```bash
node scripts/extract-legacy-assets.mjs
```
